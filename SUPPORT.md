# Support

| | |
|---|---|
| **Channel** | E-mail to the address in your licence confirmation, or a GitHub issue for bugs that contain no tenant data |
| **Response** | Best effort, usually within **2 working days** (Monday–Friday, CET/CEST, German public holidays excluded) |
| **Languages** | English, German |
| **Covered** | Installation, updates, permissions, wrong or missing data, errors in the portal and in runs |
| **Not covered** | Operating your Azure subscription or Defender/Intune configuration, custom code changes |

**Please include:** the Gapsio version (portal sidebar), the notices of the last run (overview › notices) and – if
relevant – the output of the install or update script. **Never send** tenant data, exclusion values, screenshots with
device or user names, tokens or keys unless we explicitly agree on a secure channel.

**Microsoft API changes.** Gapsio reads Microsoft Graph and Defender APIs, some of them in *beta*. Microsoft can change
them without notice. Gapsio turns such errors into notices instead of failing, and fixes follow as patch releases –
usually within a few working days of being reported.

**Security issues** go through private vulnerability reporting, not a public issue – see [SECURITY.md](SECURITY.md).
